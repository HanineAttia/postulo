# Code de conduite

Postulo adopte le **Contributor Covenant, version 2.1**, comme code de conduite pour tous ses espaces : dépôt, issues, discussions et revues de code.

- Texte officiel en français : https://www.contributor-covenant.org/fr/version/2/1/code_of_conduct/
- Texte officiel en anglais : https://www.contributor-covenant.org/version/2/1/code_of_conduct/

En résumé : nous nous engageons à faire de la participation à ce projet une expérience sans harcèlement pour tout le monde, quels que soient l'âge, la taille, le handicap visible ou invisible, l'origine ethnique, les caractéristiques sexuelles, l'identité et l'expression de genre, le niveau d'expérience, l'éducation, le statut socio-économique, la nationalité, l'apparence, la couleur de peau, la religion ou l'orientation sexuelle.

## Signalement

Pour signaler un comportement inacceptable, contacte la mainteneuse en privé via son profil GitHub ([@HanineAttia](https://github.com/HanineAttia)). Tous les signalements sont traités rapidement et de façon confidentielle.
